REQUERIMIENTOS TUTIFRUTTI

1. Crear jugador con nombre.
2. Elegir al azar una letra del abecedario para jugar.
3. Crear categorías: nombre, color, animal, país, frutas o verduras, cosas y verbos.
4. Puntuar las palabras, si es correcta 10 puntos, en caso de que se repita con un jugador, 5 puntos y si
el campo está vacío, no tiene puntuación. Sumar las puntuaciones de cada palabra.
5. Calcular el puntaje de cada jugador en la partida.
6. Validar que las palabras sean correctas según la categoría.
7. Presionar a Tuttifrutti para terminar el juego.
8. Pintar los campos dónde no exista ninguna palabra con la letra que se está jugando.
9. Ingresar las palabras en cada campo que comiencen  con la letra que salió al azar, las palabras en
mayúscula o minúscula serán permitidas, pero si le falta una letra o están mal escritas, no se tomarán cómo válidas.
10. Calcular el ganador del juego.
11. Detectar si la letra aleatoria se repite, en ese caso, elegir otra.
