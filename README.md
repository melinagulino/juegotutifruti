REQUERIMIENTOS TUTIFRUTTI

1. Crear jugador con nombre.
2. Elegir al azar una letra del abecedario para jugar.
3. Crear el nivel fácil con las categorías: nombre, color, animal, país, frutas o verduras, partes de la casa.
4. Crear el nivel intermedio con las categorías: indumentarias, electrodomésticos, medios de transporte, profesión,
sustantivo y verbo.
5. Crear nivel difícil con las categorías: Partes del cuerpo, adjetivos, deportes, nombres de famosos, plantas,
series o películas.
6. Puntuar las palabras, si es correcta 10 puntos, en caso de que se repita con un jugador, 5 puntos y si
el campo está vacío, no tiene puntuación.
7. Sumar todas las puntuaciones.
8. Calcular quién es el ganador.
9. Validar que las palabras sean correctas según la categoría.
10. Presionar a Tuttifrutti para terminar el juego.
11. Pintar los campos dónde no exista ninguna palabra con la letra que se está jugando.
12. Ingresar las palabras en cada campo que comiencen  con la letra que salió al azar, las palabras en
mayúscula o minúscula serán permitidas, pero si le falta una letra o están mal escritas, no se tomarán cómo válidas.
